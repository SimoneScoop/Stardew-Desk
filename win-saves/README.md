# Stardew Desk 存档与自定义版 0.5.1

Windows 10/11 x64 的实验性扩展，提供两个启动入口，共用一套源码。原版应用可继续使用，配置目录彼此独立。

| 模式 | 场景来源 | 本机要求 | 设置目录 |
| --- | --- | --- | --- |
| 存档版 | 只读解析自己的农场存档，重建最后保存的布局 | Steam/GOG 版《星露谷物语》及存档 | `%APPDATA%/Stardew Desk Saves` |
| 独立自定义版 | Stardew Desk 原版编辑器及本机导出的素材包 | 已准备的独立素材包；运行时不读取游戏或存档 | `%APPDATA%/Stardew Desk Custom` |

仓库只包含源码和应用图标，不分发游戏贴图、字体、音乐、存档或肖像模组。独立素材包由用户在自己的电脑上生成，保留在本地。

0.5.1 修正快捷方式箱的白纸图标：直接读取 ICO、EXE 和 DLL 的图像资源并保留图标编号，支持 UTF-16 网页快捷方式；刷新时重新读取图标，不可用时显示名称标记。

## 从源码启动

需要 Node.js 22 或更新版本，以及 Windows 10/11 x64。

```powershell
cd win-saves
npm ci
npm test
npm run start:save
```

存档版会识别 `%APPDATA%/StardewValley/Saves`，首次也可手动选择游戏的 `Content` 文件夹。选择存档后点击“载入农场”。任务栏托盘用于打开设置、配乐、屏保、原版工具和退出。`npm start` 会记住上次使用的模式；两个明确的启动命令可以覆盖该选择。

独立模式直接启动，无需先打开存档版：

```powershell
npm run start:custom -- --asset-pack="C:/path/to/standalone-pack"
```

也可在首次启动时选择已解压的素材包文件夹。发布时可以把自己的素材包放在程序的 `resources/standalone-pack/`；不要提交或公开上传该目录。源码运行时优先使用 `--asset-pack` 或界面导入的路径。当前没有为此扩展提供签名安装程序。

## 存档模式

- 按存档重建建筑、耕地、生长阶段、树木、道路、围栏、机器与动物；支持原版八种农场的地图映射。自动等待保存文件稳定后刷新，读取失败时保留上一帧，不修改存档。
- 桌面保持比例并铺满屏幕，可平移、缩放、按农场记住视角。支持存档季节、现实天气和昼夜。
- 点击农场箱子，按物品格显示用户桌面及公共桌面的快捷方式；支持搜索、分页、拖动排序，各箱子分别保存顺序。原快捷方式保持原位，只有用户点击格子时才启动对应文件。箱子不读取游戏库存。
- 14 位可邀请村民，提供参考角色性格的原创对话、聊天、跟随、个人动作及告别。告别后沿地图上方或左侧的真实出口离场。
- 桌面好感按农场独立保存，最高 10 心，每日互动奖励有限制；不修改游戏内好感或物品。
- 对话框、设置和快捷箱使用本机游戏字体。默认使用游戏肖像；可在设置文件中指定 `portraitModDir`，读取本机 OhoDavi Content Patcher 肖像包的普通/冬季变体，不捆绑模组图片。无对应模组图片时保留游戏肖像。
- 沿用原版配乐、专注种田、公告板、宠物、野生小动物、信箱提醒和屏保。真实作物保持存档状态；专注种田使用额外的装饰作物。
- 修正动画地块边缘、作物阶段、建筑门板与出货箱盖、动物方向、草丛遮挡与回摆，以及缩放后精灵帧串色的问题。

## 独立自定义模式

使用原版 Stardew Desk 场景及布置界面，可拖动农舍、鸡舍、牛棚、马厩、田地、树和物件，新增/删除作物田，绘制道路、围栏、路灯。配乐、天气、专注、公告板、宠物与屏保沿用原版工具；快捷方式箱从托盘打开。独立场景沿用原版 6 位访客，不包含存档渲染器的 14 位村民互动系统。

布局自动保存，托盘可导入/导出场景 JSON，以及导入/导出素材包。素材包只接受清单中的数据和媒体，验证大小、路径和 SHA-256，不执行包内脚本。独立入口在加载存档解析与游戏素材模块之前选定。

### 在自己的电脑上生成素材包

先在存档版加载一个农场，使游戏字体缓存准备完成。通过“原版全部功能”中的原版场景/设置读取完整的原版场景素材；需要配乐时先启用并播放，或者把下面的 `--content` 指向游戏 `Content` 目录来导出季节音乐。

退出应用后执行以下命令。`--scene-cache` 必须指向包含 `farm.js` 和 `img/` 的原版场景缓存目录；默认使用本扩展的缓存位置。输出文件夹必须尚不存在，建议放在仓库之外。

```powershell
npm run pack:assets -- --content="C:/path/to/Stardew Valley/Content" --output="C:/LocalAssets/Stardew-Desk-Pack"
# 缓存不在默认位置时可另加：
# --scene-cache="C:/path/to/original/scene/data"
```

脚本只读取本机游戏和缓存；输出包含四季场景、游戏字体与季节配乐，不含个人存档或桌面快捷方式。完成后可以把生成的文件夹导入独立模式；独立模式之后无需游戏安装目录。

## 功能边界

这是独立渲染器，未运行游戏引擎。建筑涂色、特殊皮肤、部分家具、模组地图和模组贴图尚未完整还原；动物和访客活动为桌面模拟，位置不会实时跟随游戏。没有 SMAPI 实时同步或游戏内操作。已在标准农场与草原农场的本地存档上进行渲染验证；其他地图仍需更多测试。

`legacy/` 保留原版宿主与编辑器的适配副本，使这项实验可以在不改动根目录 `win/`、`scene/` 和 `mac/` 的情况下独立运行；后续仍需考虑去重与共享接口。

## 数据与验证

游戏与存档只读，缓存、日志、桌面好感和设置保存在上述应用数据目录。天气请求使用 Open-Meteo；没有遥测、账号系统或存档上传。导出/分享场景或素材包是用户主动执行的本地操作。

`npm test` 包含 37 项测试：XML 校验与路径限制、存档解析、相机及移动、贴图帧、草丛回摆、村民性格/导航/好感、肖像选择、快捷方式排序、素材包验证与导出。另已在 Windows 本机验证两个农场的只读载入、对话框与原版工具；独立模式使用全新配置目录并拦截游戏和存档读取，未发现访问尝试。真实存档、截图与包含个人路径的集成报告不提交到仓库。

## 代码与许可

`main.cjs` 管理存档模式；`save-reader.cjs` 解析 XML；`assets.cjs` 提取本机素材；`ui/renderer.js` 绘制农场；`standalone-main.cjs` 是独立入口；`standalone-pack.cjs` 管理媒体包；`legacy/host.cjs` 接入原版工具；`winapi.cjs` 处理桌面窗口层。
